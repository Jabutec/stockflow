# StockFlow

A CLI product inventory manager, built to level up my Python skills
past basics — CRUD operations on products, starting in-memory with
plans to add persistence, customers, and sales tracking.

# Features:

- \*\*Product management
- \*\* Inventory tracking
- \*\*Sales recording
- \*\*Sales history

## 📈 Development Progress

StockFlow is being built incrementally, with each milestone adding real-world business system features.

| Week   | Focus                            | Status                                                                              |
| ------ | -------------------------------- | ----------------------------------------------------------------------------------- |
| Week 1 | CRUD Foundation                  | Completed basic product management with create, read, update, and delete operations |
| Week 2 | Data Persistence                 | Added JSON file storage with save/load functionality                                |

## About StockFlow

StockFlow is a learning-driven business management system built to strengthen my Python development skills by gradually evolving a basic CRUD application into a more complete inventory and sales management solution.

The project focuses on applying real software development concepts such as:

- CRUD operations
- Data persistence
- Input validation
- Object-oriented programming
- Reporting and analytics
- Database integration

The goal is to simulate how real business systems are designed, improved, and scaled over time.
