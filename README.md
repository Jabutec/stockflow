# StockFlow

A CLI product inventory manager, built to level up my Python skills
past basics — CRUD operations on products, starting in-memory with
plans to add persistence, customers, and sales tracking.

# Features:

- \*\*Product management
- \*\* Inventory tracking
- \*\*Sales recording
- \*\*Sales history
